개인정보처리방침

Expecto · 시행일 2026년 11월 25일

Expecto는 이름, 이메일, 전화번호를 받지 않습니다. 광고, 추적, 데이터 판매도 하지 않습니다.

서버에 저장하는 정보

  • 익명 계정 ID: 앱을 처음 열 때 만드는 무작위 번호입니다. 기기 키체인과 서버에 저장되며 실명과 연결되지 않습니다.
  • 투표: 어떤 예측에 무엇을 골랐는지.
  • 올린 예측과 댓글: 내용, 올린 시각, 표시 이름(닉네임 또는 인스타그램 아이디를 적은 경우 그 이름).
  • 신고: 어떤 예측이나 댓글을 신고했는지와 사유.

이 정보는 투표 비율 계산, 댓글 표시, 신고 처리에만 씁니다.

기기에만 저장하는 정보

  • 관심 분야, 닉네임, 인스타그램 아이디, 좋아요, 저장한 항목, 보낸 기록.

외부로 연결되는 경우

  • 뉴스: 앱이 연합뉴스, BBC, CNBC, NASA 등 언론사의 공개 RSS를 직접 불러옵니다. 이때 해당 언론사 서버가 일반적인 접속 정보(IP 주소 등)를 받을 수 있습니다.
  • 보내기: 카드를 보낼 때 아이폰 공유 창을 쓰며, 무엇을 어디로 보낼지는 사용자가 고릅니다.

처리 위탁과 국외 이전

서버와 데이터베이스는 Cloudflare, Inc.(미국)의 Workers와 D1을 씁니다. 위의 서버 저장 정보가 Cloudflare의 전 세계 데이터센터에서 처리될 수 있습니다. 앱을 쓰는 동안 이전되며, 아래 방법으로 삭제할 때까지 보관합니다.

보관과 삭제

정보는 사용자가 지울 때까지 보관합니다. 앱의 내 계정 → 설정 → 내 데이터 삭제를 누르면 투표, 댓글, 신고, 아무도 투표하지 않은 내 예측이 바로 지워집니다. 다른 사람이 이미 투표한 예측은 결과를 지키기 위해 작성자 정보만 지우고 남겨 둡니다. 앱을 삭제하면 기기에 저장된 정보도 지워집니다.
